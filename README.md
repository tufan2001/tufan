# Tufan Mondol — Bright Interactive Portfolio

A responsive portfolio website built with HTML, CSS and vanilla JavaScript. No build tools or frameworks are required.

## Run locally
1. Open this folder in Visual Studio Code.
2. Install the **Live Server** extension (Ritwick Dey) from the Extensions panel.
3. Right-click `index.html` and choose **Open with Live Server**.

You can also double-click `index.html` to preview it in your browser.

## Files
- `index.html` — page content and sections
- `style.css` — bright theme, responsive layout and animations
- `script.js` — mobile menu, scroll reveal, typing animation and current year

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `tufan-portfolio`.
2. Upload the contents of this folder (not the ZIP itself). `index.html` must be at the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then click **Save**.
6. Wait for the deployment and open the URL shown in Settings → Pages.

## Personal photo
The current hero illustration is made with CSS and Unicode symbols, so no photo is required yet. If you want a portrait, place it in an `assets` folder and we can add it to the hero section in a later edit.

## Before publishing
Check your email, LinkedIn URL, internship dates and education details. This portfolio intentionally leaves out sensitive personal information such as NID, date of birth and blood group.
